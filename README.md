# RAG Customer Service Chat Bot

A simple AI-powered customer service chatbot built using Retrieval-Augmented Generation (RAG).  
The chatbot is trained on company data and can answer common customer questions in a conversational way.

## Features

- Answers customer questions using company knowledge
- Retrieval-Augmented Generation (RAG) architecture
- Uses company documents/data as context
- Fast and interactive responses
- Easy to customize and extend

## Example Questions

Users can ask questions like:

- What services does the company offer?
- What are your business hours?
- How can I contact support?
- What is your refund policy?
- Where are you located?

## Tech Stack

- Python
- FastAPI
- LangChain
- Vector Database
- OpenAI / LLM APIs
- Docker
